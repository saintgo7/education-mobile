# Mobile Development Education Repository

A comprehensive collection of mobile development projects covering various frameworks, patterns, and best practices.

## 📱 Projects Overview

### 1. React Native Expo
- **Path**: `react-native-expo/`
- **Tech Stack**: Expo, React Navigation, Redux Toolkit
- **Features**: 5+ screens, state management, API integration, authentication

### 2. Flutter BLoC
- **Path**: `flutter-bloc/`
- **Tech Stack**: Flutter, BLoC pattern, Firebase
- **Features**: State management with BLoC, Firebase integration, authentication

### 3. Kotlin Android
- **Path**: `kotlin-android/`
- **Tech Stack**: Kotlin, Jetpack Compose, Room Database
- **Features**: Modern Android development, Compose UI, MVVM architecture

### 4. Swift iOS
- **Path**: `swift-ios/`
- **Tech Stack**: SwiftUI, Core Data, Combine
- **Features**: Native iOS development, SwiftUI interfaces, local persistence

### 5. Ionic Hybrid
- **Path**: `ionic-hybrid/`
- **Tech Stack**: Ionic, Angular, Capacitor
- **Features**: Hybrid app development, native plugins, cross-platform

### 6. React Native CLI
- **Path**: `react-native-cli/`
- **Tech Stack**: React Native (bare), Native Modules
- **Features**: Bare React Native setup, custom native modules

### 7. Flutter Riverpod
- **Path**: `flutter-riverpod/`
- **Tech Stack**: Flutter, Riverpod, Dio
- **Features**: Advanced state management, dependency injection

### 8. Cross-Platform UI
- **Path**: `cross-platform-ui/`
- **Tech Stack**: Shared UI components library
- **Features**: Reusable components, design system

### 9. Mobile Backend
- **Path**: `mobile-backend/`
- **Tech Stack**: Node.js, Express, MongoDB, JWT
- **Features**: REST API, authentication, database integration

### 10. Push Notifications
- **Path**: `push-notifications/`
- **Tech Stack**: FCM, APNS, Node.js
- **Features**: Push notification implementation for iOS and Android

## 🚀 Getting Started

Each project contains:

- State management implementation

## 🛠️ Prerequisites

### General Requirements
- Git
- Node.js (v18+)
- npm or yarn
- Code editor (VS Code recommended)

### Platform-Specific Requirements

#### React Native Projects
- Node.js v18+
- React Native CLI / Expo CLI
- Android Studio (for Android)
- Xcode (for iOS, macOS only)

#### Flutter Projects
- Flutter SDK (3.0+)
- Dart SDK
- Android Studio / Xcode

#### Native Android
- Android Studio
- JDK 11+
- Kotlin plugin

#### Native iOS
- macOS
- Xcode 14+
- CocoaPods

## 📚 Learning Path

### Beginner
1. Start with **react-native-expo** - easiest setup
2. Explore **ionic-hybrid** - web technologies
3. Try **mobile-backend** - understand API integration

### Intermediate
4. Learn **flutter-bloc** - different framework
5. Explore **react-native-cli** - bare React Native
6. Study **flutter-riverpod** - advanced state management

### Advanced
7. Master **kotlin-android** - native Android
8. Learn **swift-ios** - native iOS
9. Build **cross-platform-ui** - shared components
10. Implement **push-notifications** - complete integration
